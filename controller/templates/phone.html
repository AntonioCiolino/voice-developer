Using the controller

Describe your app in the prompt, then choose Plan. The generated app appears in the preview below.

Plan creates a plan and a task list. The tasks start automatically after 5 seconds. Click the button during the countdown to cancel, or close the plan window.

Continue plan resumes the latest stored plan from its next pending or failed task. A failed task stops the run and only that task's changes are undone. Where the code runs (local or cloud, which model) is set in the ⚙ models panel, or by PLANNER_* and CODER_* in controller/.env when nothing is chosen there, not by the button.

Save App stores the current app. Load App restores a saved app. The name above these buttons is the app in the preview; Save App offers it again, so saving replaces that app's saved copy unless you type a new name.

New App clears the current app. Use ⟳ to reload the preview.

log opens the latest task error or output for troubleshooting.
